## Performing a Conditional Search

This lab focused on performing conditional searches in a relational database using the SELECT statement together with the WHERE clause. The database used in this lab was world, which contains three tables:
- city
- country
- countrylanguage
  
The objective was to filter and retrieve specific records from the country table using different SQL operators and functions.


## Lab Objectives

By completing this lab, I learned how to:

- Write search conditions using the WHERE clause

- Use the BETWEEN operator for range filtering

- Use the LIKE operator with wildcard characters

- Create column aliases using the AS keyword

- Apply aggregate functions in a SELECT statement

- Use functions within a WHERE clause
