# AWS-Re-Start-Journey

This repository documents my learning journey while studying for the AWS Certified Cloud Practitioner certification. During this course, I gained foundational knowledge of cloud computing and developed hands-on experience working with core services in Amazon Web Services (AWS).

My goal in completing this course was to understand how cloud technology works, how businesses use cloud solutions, and how to design secure and scalable cloud environments. Through a combination of theory, labs, and practical exercises, I learned the fundamental concepts of cloud computing and how to apply them using AWS tools and services.

This repository serves as a record of the labs, exercises, and projects I completed throughout my cloud learning journey.

What I Learned
1. ## Cloud Computing Fundamentals

I started by learning the basic concepts of cloud computing. I gained an understanding of:
What cloud computing is and how it differs from traditional on-premises infrastructure
The benefits of cloud computing such as scalability, reliability, and cost efficiency
Different cloud service models including Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS)
The different cloud deployment models such as public cloud, private cloud, and hybrid cloud
These concepts helped me understand why many organizations are moving their infrastructure to the cloud.

2. ## Core AWS Services

I learned how to use several key services in AWS that form the foundation of cloud architecture. These include:

**Amazon EC2** – launching and managing virtual servers in the cloud

**Amazon S3** – storing and managing data in scalable object storage

**Amazon VPC** – creating isolated networks in the cloud

**Amazon RDS** – managing relational databases in the cloud
Through hands-on labs, I learned how to configure these services and understand how they work together to support cloud applications.

3. ## Cloud Networking
I also learned about networking in the cloud and how AWS enables secure communication between resources. Some of the networking concepts I practiced include:

- Creating a Virtual Private Cloud (VPC)

- Configuring subnets and route tables

- Attaching an internet gateway

- Managing traffic using security groups and network access control lists

These labs helped me understand how to design secure and well-structured cloud networks.

4. ## Security and Identity Management

Security is a critical part of cloud computing. During the course, I learned how AWS manages security using identity and access control.
I worked with AWS Identity and Access Management (IAM) to:
- Create users and roles
- Assign permissions and policies
- Implement the principle of least privilege
- This helped me understand how organizations control access to cloud resources and protect sensitive data.

5. ## Databases and Storage
Another important area I explored was cloud storage and database services. I learned how AWS provides scalable solutions for storing data and managing databases.
Key topics included:
- Object storage using Amazon S3

- Relational databases with Amazon RDS

- Data durability and availability

- Backup and recovery strategies

These services help organizations store and manage large amounts of data efficiently.

6. ## Hands-On Labs and Practical Experience
Throughout the course, I completed several hands-on labs using the **AWS Cloud9** integrated development environment and the AWS Management Console.

Some of the practical tasks I completed include:

- Launching and connecting to EC2 instances

- Creating and configuring VPC networks

- Setting up IAM users and permissions

- Writing Python scripts in Cloud9

- Working with databases using MySQL clients

These labs allowed me to apply the concepts I learned and gain practical experience working in the AWS cloud environment.

## Key Skills I Developed
During this learning journey, I developed skills in:
- Cloud infrastructure fundamentals
- AWS service configuration
- Cloud networking and security
- Basic scripting with Python
- Managing and deploying resources in AWS

## Conclusion

Completing the Cloud Practitioner course has given me a strong foundation in cloud computing and AWS services. It has helped me understand how modern cloud systems are designed and managed. This learning journey has strengthened my interest in cloud technology, and I plan to continue building my skills through more advanced AWS training and hands-on projects.
