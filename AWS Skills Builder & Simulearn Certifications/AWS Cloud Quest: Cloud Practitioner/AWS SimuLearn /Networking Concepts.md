## 🌐 Networking Concepts

### 📌 Overview

In this exercise, I explored the fundamentals of AWS networking by examining the key components of Virtual Private Clouds (VPCs). I designed network architectures using subnets and gateways, applied IP addressing and CIDR notation for network planning, and configured routing and security controls to manage traffic flow within the cloud environment.

---

### Services I Worked With

* **Amazon VPC** — Used to create isolated and customizable virtual networks with subnets, gateways, and routing configurations
* **Amazon Elastic Compute Cloud (EC2)** — Deployed within the VPC environment to test connectivity and validate routing configurations

---

### What I Demonstrated

Through this SimuLearn exercise, I demonstrated an understanding of:

* VPC architecture and networking components such as subnets, internet gateways, and route tables
* The benefits of VPCs for network isolation, control, and security
* CIDR notation and IP addressing concepts used in network design and allocation
* Traffic routing within VPCs using internet gateways, NAT gateways, and route table configurations
* Network Access Control Lists (NACLs) for stateless traffic filtering
* Security groups as stateful firewalls for EC2 instances
* How multiple networking layers work together to manage inbound and outbound traffic securely
