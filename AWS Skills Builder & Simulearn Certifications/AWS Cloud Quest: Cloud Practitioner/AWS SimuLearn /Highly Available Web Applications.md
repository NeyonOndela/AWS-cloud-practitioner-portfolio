
## Highly Available Web Applications
**Overview**

In this exercise, I designed and deployed a highly available web application architecture using Application Load Balancers and EC2 Auto Scaling. This SimuLearn experience provided hands-on exposure to different scaling strategies and demonstrated how load balancing efficiently distributes traffic across multiple compute resources to improve resilience and performance.

 **Services I Worked With**
* Amazon EC2 Auto Scaling — Automatically scales the number of EC2 instances based on demand and system health to ensure continuous availability
* Amazon Elastic Compute Cloud (EC2) — Provides scalable compute capacity for hosting the application
* Elastic Load Balancing (ELB) — Distributes incoming requests across multiple instances and routes traffic only to healthy targets
* Amazon S3 — Stores static content and application assets with high durability and availability

**Through this SimuLearn exercise, I demonstrated the ability to:**

* Design multi-Availability Zone architectures to maintain uptime during failures or disruptions
* Evaluate Application Load Balancer features, including path-based, host-based, and request-based routing
* Implement Auto Scaling groups with dynamic scaling policies driven by CloudWatch metrics
* Compare horizontal scaling (adding more instances) with vertical scaling (increasing instance size) and understand their trade-offs
* Configure health checks and monitoring to ensure traffic is directed only to healthy instances
* Apply distributed system principles to eliminate single points of failure and improve system reliability
