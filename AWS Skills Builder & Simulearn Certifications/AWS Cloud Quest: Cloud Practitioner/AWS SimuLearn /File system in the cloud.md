## File Systems in the Cloud
 **Overview**
 
In this exercise, I explored cloud storage solutions by evaluating different AWS storage services and examining the features and advantages of Amazon EFS. I applied EFS to practical business scenarios and configured centralized file storage that could be accessed by multiple EC2 instances.

**Services I Worked With**


* Amazon Elastic File System (EFS) — A fully managed and scalable network file system that provides shared storage with high availability and durability across multiple EC2 instances
* Amazon Elastic Compute Cloud (EC2) — Configured compute resources to connect to and use centralized EFS storage



## What I Demonstrated

Through this SimuLearn exercise, I demonstrated an understanding of:

* Different AWS storage options and their use cases, including block, object, and file storage

* The core features and architectural advantages of Amazon EFS for shared storage environments

* EFS scalability, performance, and high availability across multiple Availability Zones

* Implementing EFS solutions for business scenarios requiring centralized shared file systems

* Configuring EFS mount targets and endpoints for access across multiple EC2 instances

* Managing security and access permissions for shared file storage

* Evaluating cost and performance optimization strategies for EFS deployments
