
## Computing Solutions

### Overview

In this exercise, I explored the capabilities of Amazon EC2 and strategies for optimizing compute resources. I compared different instance families and types, evaluated scaling techniques, configured access methods, and selected instances based on specific workload needs.

---

### Services I Worked With

* **Amazon Elastic Compute Cloud (EC2)** — Used to provision and manage virtual servers with various instance types tailored to different performance, scalability, and workload requirements

---

### What I Demonstrated

Through this SimuLearn exercise, I demonstrated an understanding of:

* The different EC2 instance families and types, and how they align with various workloads
* Scaling approaches, including both vertical and horizontal scaling
* Practical methods for scaling EC2-based infrastructure
* Configuration and connection options for securely accessing EC2 instances
* Analyzing workloads to choose the most suitable instance types for performance and cost efficiency
* The trade-offs between resource allocation, performance, and cost when selecting instances
