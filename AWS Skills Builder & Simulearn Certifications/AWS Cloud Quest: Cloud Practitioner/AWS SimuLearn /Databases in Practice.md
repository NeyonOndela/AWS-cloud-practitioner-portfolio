## Databases in Practice
**Overview**

In this exercise, I explored AWS database solutions by comparing different database types and their use cases. I implemented Multi-AZ deployments to improve high availability, configured read replicas to enhance performance, and evaluated migration strategies using AWS database services.

**Services I Worked With**


* Amazon Relational Database Service (RDS) — A fully managed relational database service that supports multiple database engines, automated backups, high availability, and read scaling capabilities
* AWS Database Migration Service (DMS) — Used to assess, migrate, and replicate databases from on-premises environments or other cloud platforms to AWS



**What I Demonstrated**
Through this SimuLearn exercise, I demonstrated an understanding of:


* Different AWS database types and the scenarios best suited for each

* Relational database concepts and architectural design principles

* Implementing Multi-AZ deployments to improve database availability and fault tolerance

* Configuring read replicas to scale read-intensive workloads and improve performance

* Performance optimization techniques, including replica placement and replication lag management

* The differences and trade-offs between managed and self-hosted database solutions

* Database migration planning, assessment, and execution using AWS DMS

* Migration approaches such as full data loads, ongoing replication, and cutover strategies

* Managing data consistency and minimizing downtime during database migrations
