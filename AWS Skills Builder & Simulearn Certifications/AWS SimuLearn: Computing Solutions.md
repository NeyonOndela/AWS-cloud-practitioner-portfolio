## Introduction

In this lab, I explored different features of Amazon EC2 and learned how to manage EC2 instances using the AWS Management Console. The purpose of the lab was to understand EC2 instance types, how to filter instances based on their attributes, connect to an instance, view instance metadata, and manage the instance state.

## Exploring EC2 Instance Types

During the lab, I explored the different instance types available in Amazon Elastic Compute Cloud. I learned that EC2 provides various instance families designed for different workloads such as general purpose, compute optimized, and memory optimized. Each instance type has specific CPU, memory, storage, and networking capabilities, which makes it important to choose the correct instance type depending on the application requirements.

## Filtering EC2 Instances

I also practiced filtering EC2 instances using the filtering options in the EC2 console. This allowed me to search and organize instances based on attributes such as instance type, instance state, availability zone, and tags. Using filters makes it easier to manage multiple instances in large cloud environments.

## Connecting to an EC2 Instance

In this lab, I connected to a running EC2 instance using EC2 Instance Connect. This method allowed me to securely access the instance directly from the browser without needing additional SSH software. Through this connection, I was able to interact with the instance and confirm that it was running correctly.

## Viewing Instance Metadata

I viewed the EC2 instance metadata by accessing it through the instance’s public IP address. The metadata provided useful information about the instance, including the instance ID, instance type, and networking details. This information is helpful for applications running inside the instance that need to access configuration details.

## Starting and Stopping an Instance

Finally, I practiced starting and stopping an EC2 instance using the EC2 console. I learned that stopping an instance shuts down the virtual server while preserving its configuration, and starting it again restores the instance so it can continue running workloads.

## Conclusion

Overall, this lab helped me gain practical experience with EC2 instance management. I learned how to explore instance types, filter instances, connect to instances, view metadata, and control the instance state. These skills are essential for managing cloud infrastructure and working effectively with AWS compute services.
